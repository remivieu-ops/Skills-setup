🎯 360Learning — Skills Ontology Setup

⚠️ This runs entirely in your browser — nothing is sent anywhere except directly to the 360Learning API domain you select. Your Client ID/Secret are never stored or transmitted elsewhere, but avoid using this on a shared computer. If your company's 360Learning environment doesn't allow direct browser calls (CORS), see the note at the bottom of Step 4.

1 · API Credentials Step 1 & 2 of the 360Learning guide

Get these from Settings → API v2 → + Add API Credentials in the demo account (platform admin/owner only). Required scopes: skillsLibraries:bulk, skills:bulk, skillsJobs:bulk, skillsJobSkills:bulk, skills:read, bulkOperations:read.

🌐 Getting a CORS / "Failed to fetch" error? Use a proxy

360Learning's API doesn't allow direct browser calls (no CORS headers), so a static page like this one can't reach it directly. Deploy the free Cloudflare Worker proxy from this tool's repo (cloudflare-worker-proxy.js, see README) and paste its URL below — every request will be routed through it instead of calling 360Learning directly.

2 · Build the Skills Ontology data Library → Skill → Job → Job‑Skill

Fill in the ontology below, or load the ready-made demo dataset. Every object uses an externalId you choose — re-running with the same IDs safely upserts (creates or replaces) rather than duplicating.

📚 Libraries — upload CSV/XLSX
Columns: externalId*, name*, description, status (draft|published)
🧩 Skills — upload CSV/XLSX
Columns: externalId*, name*, description, parentExternalIds* (one or more library/skill externalIds separated by ;)
💼 Jobs — upload CSV/XLSX
Columns: externalId*, name*, description, parentExternalId (for job hierarchy, optional)
🔗 Job ↔ Skill mapping — upload CSV/XLSX (optional, needs internal IDs — see Step 4)

This endpoint requires 360Learning's internal jobId/skillId (not your externalIds). Create Libraries/Skills/Jobs first (Step 3), use Step 4 to fetch the resulting internal IDs, put them in your file, then upload here and re-run just this step.

Columns: jobId* (internal), skillId* (internal)

3 · Run the setup

Runs in order: Libraries → Skills → Jobs → (optional) Job‑Skills. Each call is a bulk upsert and returns an async operation that this tool polls until it finishes.



    

      CORS note: the 360Learning API is meant to be called server-to-server and typically blocks direct browser requests. If Step 1 failed with "Failed to fetch", set a Proxy base URL in Step 1 (see the collapsible note there) using the free Cloudflare Worker proxy in this tool's repo, or run these same requests from a small server-side script (Node/Python) instead — the request bodies logged below are copy-paste ready for curl/Postman.
